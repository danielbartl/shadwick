Shadwick

shadcn/ui-style components for Apache Wicket, rendered on the server. Switch the skin and light or dark mode at the top of every page.

  • Buttons: every variant and size, on links and buttons
  • Form: text fields with validation, submitted normally and over Ajax
  • Inputs: email, password, search, telephone, URL and typed numbers
  • Choices: checkboxes, switches and radio groups, including immediate Ajax updates
  • Month view: native agenda navigation and custom day content
  • Charts: bars, lines, areas, keyboard tooltips and exact data
  • Calendar & date picker: date and range grids, native fallbacks and locale-aware navigation
  • Combobox: search, multiple chips and server-backed choices
  • Custom select: grouped choices, icons and progressive native pickers
  • Selections: native dropdowns, multi-select lists and checkbox groups
  • Dates & time: native date, time, local date/time, month and week fields
  • Groups: toggles, single/multiple selections, input addons and actions
  • Uploads: native file inputs, dropzones and multipart validation
  • Dialog: opened in the browser, over Ajax, and one with a form
  • Overlays: reusable confirmations and sheets from every edge
  • Popovers & tooltips: anchored content, quick forms and keyboard hints
  • Menus: actions, navigation links, checked choices and keyboard navigation
  • Toasts: direct notifications, timing, keyboard access and modal support
  • Theme & preferences: Light/Dark/System, remembered choices and synchronized controls
  • App layouts: reusable sidebar/header compositions, submenus, badges and actions
  • Tables: native cells, compact spacing, column groups and a pinned first column
  • Pagination: summaries, page sizes and independent bookmarkable lists
  • Data tables: sorting, filters, selection, row actions and bookmarkable pagination
  • Attachment displays: file cards, image previews, native downloads and galleries
  • Tabs & disclosures: bookmarkable tabs, native accordions and collapsibles
  • User menu: account menus in the header and sidebar, sign-in and sign-out
  • Sidebar: responsive navigation, icon rails and grouped links
  • App shell: headers, breadcrumbs and keyboard shortcuts to the content
  • Display: cards, badges, alerts, avatars, loading states and icons
  • Feedback: form messages and persistent, dismissible toasts
  • Internationalization: nine languages, locale-aware controls and application overrides
  • Advanced tables: column choices, CSV downloads, row details and validated inline edits
  • Progress & ratings: busy buttons, progress bars/rings, native meters and star ratings
