# Shadwick

shadcn/ui-style UI components for [Apache Wicket](https://wicket.apache.org): shadcn's look,
tokens and component catalog, rendered on the server by Wicket. Add one Maven dependency and you're
done: no Node, no Tailwind, no CSS build in your application.

> Work in progress (Phase 1: button, text field, dialog).

Shadwick is inspired by [Shadleaf](https://github.com/wimdeblauwe/shadleaf), shadcn/ui for
Thymeleaf. It is not affiliated with or endorsed by Shadleaf or shadcn/ui. Its Java API follows
[Wicket Oat](https://github.com/danielbartl/wicket-oat).
