# Choose a component family

The links below lead to Markdown guides with matching markup and source-derived API signatures. Use them to
verify constructors, callback shapes and slots for the task. Several controls share a family guide.

| Need | Starting point | Guide |
| --- | --- | --- |
| Actions or submit buttons | `SwButton`, `SwSubmitButton`; button behaviors for existing links | [Buttons](https://danielbartl.github.io/shadwick/docs/components/buttons/index.md) |
| Labeled fields and validation | `SwTextField`, typed models and a Wicket `Form` | [Forms](https://danielbartl.github.io/shadwick/docs/components/forms/index.md) |
| Email, numbers, search, multiline text | Typed field wrappers | [Inputs](https://danielbartl.github.io/shadwick/docs/components/inputs/index.md) |
| Boolean/radio choices | Checkbox, switch and radio controls | [Choices](https://danielbartl.github.io/shadwick/docs/components/choices/index.md) |
| Native single/multiple choice | Native select controls | [Native selects](https://danielbartl.github.io/shadwick/docs/components/native-selects/index.md) |
| Rich single choice | `SwSelect` | [Custom select](https://danielbartl.github.io/shadwick/docs/components/select/index.md) |
| Searchable or multiple choice | `SwCombobox`, `SwMultiCombobox` | [Combobox](https://danielbartl.github.io/shadwick/docs/components/combobox/index.md) |
| Freeform labels or tags | `SwTagInput`, `TagInputBehavior` | [Freeform tags](https://danielbartl.github.io/shadwick/docs/components/tag-input/index.md) |
| Date/time input | Native typed fields | [Date and time](https://danielbartl.github.io/shadwick/docs/components/date-time/index.md) |
| Calendar or date range | `SwCalendar`, `SwDatePicker`, range equivalents | [Calendar](https://danielbartl.github.io/shadwick/docs/components/calendar/index.md) |
| Agenda | `SwMonthView` | [Month view](https://danielbartl.github.io/shadwick/docs/components/month-view/index.md) |
| Charts, forecasts, rankings and small trends | `SwChart`, `ChartSeries`, `SwDonutChart`, `SwSparkline` | [Charts](https://danielbartl.github.io/shadwick/docs/components/charts/index.md) |
| Toggle buttons or field addons | Toggles and input groups | [Groups](https://danielbartl.github.io/shadwick/docs/components/toggles-input-groups/index.md) |
| Upload a file | `SwFileUpload`; application-owned storage | [Upload](https://danielbartl.github.io/shadwick/docs/components/file-upload/index.md) |
| Show existing files | `SwAttachment`, `SwAttachmentGroup` | [Attachments](https://danielbartl.github.io/shadwick/docs/components/attachments/index.md) |
| Dialog/form overlay | `SwDialog` | [Dialogs](https://danielbartl.github.io/shadwick/docs/components/dialog/index.md) |
| Confirm an action | `SwConfirmDialog` | [Confirmation](https://danielbartl.github.io/shadwick/docs/components/confirmation-dialog/index.md) |
| Side panel | `SwSheet` | [Sheets](https://danielbartl.github.io/shadwick/docs/components/sheet/index.md) |
| Anchored content/help | Popover or tooltip components/behaviors | [Popover](https://danielbartl.github.io/shadwick/docs/components/popover/index.md), [tooltip](https://danielbartl.github.io/shadwick/docs/components/tooltip/index.md) |
| Menu actions or account navigation | Dropdown menu and `SwUserMenu` | [Menus](https://danielbartl.github.io/shadwick/docs/components/dropdown-menu/index.md), [user menu](https://danielbartl.github.io/shadwick/docs/components/user-menu/index.md) |
| Notifications or validation messages | Toast helpers and `SwFeedbackPanel` | [Toasts](https://danielbartl.github.io/shadwick/docs/components/toasts/index.md), [feedback](https://danielbartl.github.io/shadwick/docs/components/feedback/index.md) |
| Data from a sortable/paged provider | `SwDataTable`, standard Wicket columns | [Data table](https://danielbartl.github.io/shadwick/docs/components/data-table/index.md) |
| Inline edits, CSV or column choice | Data-table options and editing columns | [Advanced tables](https://danielbartl.github.io/shadwick/docs/components/advanced-table/index.md) |
| Independent paging | `SwPagination` and Wicket paging helpers | [Pagination](https://danielbartl.github.io/shadwick/docs/components/pagination/index.md) |
| Workspace shell | `SwAppLayout`, `SwSidebar`, `MenuItem` | [Layouts](https://danielbartl.github.io/shadwick/docs/components/app-layout/index.md) |
| Tabs/disclosure | `SwTabs`, accordion and collapsible controls | [Tabs](https://danielbartl.github.io/shadwick/docs/components/tabs/index.md), [accordion](https://danielbartl.github.io/shadwick/docs/components/accordion/index.md), [collapsible](https://danielbartl.github.io/shadwick/docs/components/collapsible/index.md) |
| Cards, badges, avatars or loading states | Display components | [Cards](https://danielbartl.github.io/shadwick/docs/components/cards/index.md), [badges](https://danielbartl.github.io/shadwick/docs/components/badges/index.md), [loading](https://danielbartl.github.io/shadwick/docs/components/loading/index.md) |
| Overlapping team members or an avatar cluster | `SwAvatarGroup`, `AvatarGroupBehavior` | [Avatars and groups](https://danielbartl.github.io/shadwick/docs/components/avatars/index.md) |
| Connected actions | Button groups, split buttons | [Button groups and split buttons](https://danielbartl.github.io/shadwick/docs/components/button-groups/index.md) |

| Deferred report or expensive content | `SwLazyLoadPanel` | [Lazy-loaded panels](https://danielbartl.github.io/shadwick/docs/components/lazy-load/index.md) |
| Ordered process stages or current stage | `SwSteps` | [Steps indicator](https://danielbartl.github.io/shadwick/docs/components/steps/index.md) |
| Pending actions and measurements | Busy controls, progress, meters, ratings | [Busy](https://danielbartl.github.io/shadwick/docs/components/busy-controls/index.md), [progress](https://danielbartl.github.io/shadwick/docs/components/progress/index.md), [meters](https://danielbartl.github.io/shadwick/docs/components/meters/index.md), [ratings](https://danielbartl.github.io/shadwick/docs/components/ratings/index.md) |

Use the [documentation index](https://danielbartl.github.io/shadwick/llms.txt) for the remaining families and the
[live catalog](https://shadwick-production.up.railway.app/components) for runnable compositions and exact page source.
Do not translate a Shadleaf/React attribute API into Java by guesswork; inspect Shadwick's own type and guide.

Form completion: `SwFieldset` and `SwCustomField` compose native groups and compound inputs; see [fieldsets/custom fields](https://danielbartl.github.io/shadwick/docs/components/fieldsets-custom-fields/index.md). `SwMoneyField` and `SwPercentField` use exact localized `BigDecimal` values (19 means 19%); see [money/percent](https://danielbartl.github.io/shadwick/docs/components/money-percent/index.md). `SwRangeField` is a native single-value slider with server-validated bounds/step; see [range](https://danielbartl.github.io/shadwick/docs/components/range/index.md).
