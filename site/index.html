01

Install the snapshot locally

Shadwick is in active development and isn’t on Maven Central yet. Clone the repository and build it once.

git clone https://github.com/danielbartl/shadwick.git
cd shadwick
./mvnw install
02

Add it. Install it. Make it yours.

Requires Java 17+ and Wicket 10. Add the dependency, then call the installer in your application’s init().

<dependency>
  <groupId>dev.jbaby</groupId>
  <artifactId>shadwick</artifactId>
  <version>0.1.0-SNAPSHOT</version>
</dependency>
Shadwick.install(this);
