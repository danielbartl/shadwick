# Shadwick 0.1.0

Release candidate frozen on 9 November 2026 as `0.1.0`, with declared SCM tag `v0.1.0`.
Maven Central publication is pending. This is the draft body for the first GitHub release;
the tag and public release are created only after candidate review, credentials and CI are complete.

Candidate review is complete: the API and feature scope are frozen, release builds pass on Java 21 and 25,

[release preparation record](https://github.com/danielbartl/shadwick/blob/main/docs/guides/releases.md).

## What ships

Shadwick brings shadcn/ui-inspired components to Apache Wicket with familiar Java models, behaviors and callbacks.
The library ships compiled styles and browser resources in one JAR; consuming applications need no Node or
Tailwind installation.

The initial collection covers forms and validation, custom choices/comboboxes, calendars and date pickers,
dialogs/sheets/popovers, menus/tooltips/toasts, application layouts and navigation, disclosures and attachments,
editable data tables and CSV exports, SVG charts (including donuts/pies, 100% stacked bars/areas and reference lines/bands),
scatter/radar plots, radial bars, heatmaps and sparklines, and display/feedback components. It also includes
compound and numeric fields, button groups/split buttons, record details/timelines, lazy panels, tags, avatar groups
and process steps.

Nine skins support light/dark appearance and standalone/embedded integration. Built-in messages ship in English,
German, Spanish, French, Italian, Japanese, Dutch, Portuguese and Croatian. Components preserve their documented
keyboard access, native fallbacks, validation and strict nonce-based CSP behavior.

## Coordinates and requirements

The candidate coordinates are `dev.jbaby:shadwick:0.1.0`. Install this checkout locally until Central publication is confirmed.

```xml
<dependency>
    <groupId>dev.jbaby</groupId>
    <artifactId>shadwick</artifactId>
    <version>0.1.0</version>
</dependency>
```

The frozen release baseline is Java 21+, Apache Wicket 11.0.0 and Jakarta Servlet 6.1+. Keep Wicket modules aligned in the consuming
application. The library has no Spring Boot runtime dependency; the hosted examples use Spring Boot separately.
The automatic module name is `dev.jbaby.shadwick`; a tested full JPMS deployment is not claimed.

Maven Central receives the parent POM and the library's POM, binary, sources and Javadoc, with signatures and
checksums. The examples application is not a published Maven dependency.

## Compatibility and boundaries

The candidate public/protected Java API is recorded and checked during normal tests. Serialization tests cover
round trips within one build. Drain or invalidate stored pages/sessions when deploying a changed build unless the
application has verified its own migration strategy. Wicket 11 cannot decrypt Wicket 10 encrypted URLs or stored
pages; regenerate encrypted links and start fresh sessions/page stores when upgrading the earlier snapshot.
Persistence, authorization, upload storage and business rules remain application-owned.

Chromium and Firefox are the automated browser targets. Consult each component guide for native/no-script
support; nested form submission and other Ajax-only paths require JavaScript. This release covers the planned
component families, rather than every possible Wicket Oat or Shadleaf variant.
